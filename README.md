# Coffee Brew Log

A full-stack Coffee Brew Log application built for the XPL Full-Stack Developer Bootcamp assessment.

The app allows users to create, view, filter, edit, and delete coffee brew entries.

Live Demo: https://nobuhledhlamini.github.io/coffee-brew-log/

## Features

- Create a brew entry
- View all brews
- Filter brews by brew method
- Edit brew entries
- Delete brew entries
- Form validation
- Responsive design

## Technologies Used

- React
- CSS
- Node.js
- Express
- PostgreSQL
- ORM
